# Optional profile update for the account that owns this post

The one click seeder assigns the post to `admin@huvanti.com` without changing that account. If you want that author to look more like a working creator, you can update the profile in the author dashboard or admin panel with these values.

## Suggested values

- Username: keep the existing username. Usernames are one time locked and Huvanti does not let an account change them after the first save.
- Role title: Creator Strategy Editor
- Niche: technology
- Country: leave the current value unchanged because the account already has a real owner
- Bio: I write practical publishing guides for creators, with a focus on AI assisted research, SEO, editorial trust, and YouTube content systems.
- Portfolio URL: leave empty unless you have a real portfolio.
- Social links: leave your real profiles unchanged. Do not add links that do not belong to this person.

## Why the profile is not changed by the seeder

The post author on the public article will always be drawn from the user record linked to `posts.user_id`. Updating a real account name, avatar, country, or social links without the actual person's approval would misrepresent the account owner. This bundle does not create a new identity, a random Gmail address, or a fake verified badge.
